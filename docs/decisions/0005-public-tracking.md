# 0005. Track work publicly

Status: Accepted (2026-11-15)

Issue: #1

## Context

The repository is public. The owner first intended a private Kanban board, then chose to make it public.

## Decision

Work is tracked in public: issues in this repository, milestones per plan phase (A to G), and a public GitHub Project at https://github.com/users/5cover/projects/23 with the status workflow described in [AGENTS.md](../../AGENTS.md).

## Consequences

- Transparency suits an archive that asks for public trust.
- Nothing sensitive may be written in issues: no contributor data, no unredacted abuse reports, no security vulnerabilities before they are fixed. Security reports need a private channel (a `SECURITY.md` and GitHub private vulnerability reporting) before launch.
