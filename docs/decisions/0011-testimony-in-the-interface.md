# 0011. The interface calls a contribution a "testimony" ("témoignage")

Status: Accepted (2026-11-15)

Issue: #44

## Context

Plan section 38 recommended plain interface copy built on "entry" ("write an entry", "anonymous entry"), keeping "testimony" for methodology and implementation. An earlier owner decision had already made "testimony" the term in code, URLs, identifiers and documentation, replacing "voices". That left only the visible interface wording open.

## Decision

The visible interface also says "testimony", and "témoignage" in French. The owner judged the word more specific than "entry": it names what the archive collects. The surrounding copy stays plain and inviting: "sign the guestbook", "leave a testimony", "read the guestbook", "time capsule".

## Consequences

- One term across interface, code, URLs and documentation removes the translation layer between the public object and the archival record.
- Plan section 38, the [editorial principles](../constitution/editorial-principles.md) (principle 13) and [AGENTS.md](../../AGENTS.md) are updated accordingly.
- "Témoignage" can sound formal or solemn to some visitors. The plain surrounding copy and the guestbook framing must carry the "anybody can contribute" message (plan section 3), and copy reviews should check for that.
- Methodology terms such as "corpus", "archival record" or "Zeitzeugnis" stay out of the main interface.
